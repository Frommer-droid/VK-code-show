# История изменений (Release Notes)

## Версия 0.2.0 (2026-09-27)

*Scan code можно копировать отдельно; сборка проверяет native runtime и запуск EXE.*

### ✨ Новые возможности

- Отдельная карточка scan code: десятичное и шестнадцатеричное представления,
  копирование десятичного значения.

### 🎨 Интерфейс

- Карточки VK и scan code, увеличенные строки истории и тема One Dark.

### 🛡️ Безопасность

- Сборка с минимальным PATH, проверкой происхождения DLL и полным MSVC runtime Qt.
- Pillow для разработки обновлён до 12.3.0.

### 🛠 Улучшения

- Версия встроена в Windows-метаданные EXE; добавлена неинтерактивная smoke-проверка.
- Установщик определяет настоящий рабочий стол и предлагает запуск после установки.

### 📚 Документация

- README на русском и английском, MIT для собственного кода и уведомления о зависимостях.

## Версия 0.1.1 (2026-04-30)

*Обновлена основная иконка приложения.*

### 🎨 Интерфейс

- Обновлена основная иконка приложения на прозрачный 3D-вариант из
  `assets/icons/logo.png`.
- `logo.ico` пересобран как Windows ICO с размерами 16, 24, 32, 48, 64,
  128 и 256 px.

## Версия 0.1.0 (2026-04-30)

*Первая версия для просмотра кодов клавиш активного окна.*

### ✨ Новые возможности

- Первичная версия VK Code Show: захват virtual-key code активного окна,
  история нажатий, копирование VK и VKC token.
- Подготовлены PyInstaller build tools и Inno Setup release helper.
